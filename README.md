# Machine Downtime Analysis Dashboard

##  Project Overview

This project analyzes machine downtime and maintenance data using Power BI.

The dashboard helps identify high-downtime machines, major downtime reasons, repair costs, and downtime trends. It provides interactive filters for machine, technician, and shift-wise analysis.

---

##  Project Objectives

The main objectives of this project are:

- To calculate the total machine downtime.
- To identify machines with the highest downtime.
- To analyze the major reasons for machine downtime.
- To study downtime trends over time.
- To compare repair costs across different machines.
- To analyze downtime based on shifts and technicians.
- To support preventive maintenance and improve production efficiency.

##  Questions and Answers

### 1. What is the total machine downtime?

**Answer:**  
The total downtime is calculated by adding the downtime recorded for all machines. The result is converted from minutes to hours and displayed using a KPI card.

### 2. Which machine has the highest downtime?

**Answer:**  
The **Downtime by Machine** chart compares the total downtime of all machines. The machine with the longest bar has the highest downtime and may require maintenance attention.

### 3. What are the major reasons for machine downtime?

**Answer:**  
The **Downtime by Reason** donut chart shows the contribution of different downtime reasons. The largest section represents the major cause of downtime.

### 4. How does downtime change over time?

**Answer:**  
The **Downtime Trend Over Time** line chart shows changes in machine downtime across different dates. Peaks indicate periods of high downtime.

### 5. Which machine has the highest repair cost?

**Answer:**  
The **Repair Cost by Machine** chart compares repair costs across machines. The machine with the highest bar has the highest repair cost.

### 6. How can shift-wise downtime be analyzed?

**Answer:**  
The Shift filter allows users to select Shift A, B, or C. The dashboard updates automatically based on the selected shift.

### 7. How can technician-wise data be analyzed?

**Answer:**  
The Technician filter allows users to analyze machine downtime and maintenance information for a selected technician.
